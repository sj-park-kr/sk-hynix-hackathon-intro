# SK하이닉스 AI 해커톤 2026 — 1·2차 예선 대비 자료 (소개용)

SK하이닉스 AI 해커톤 2026 1차 예선(AI 역량 검사)과 2차 예선(크래프톤 Cofa Probe, AI 활용 실무형 과제)을 준비하면서 만든 자료가 있습니다.
**본 자료는 비공개 저장소에 있고, 이 저장소에는 어떤 내용이 있는지만 적었습니다.**

## 1차 예선 (AI 역량 검사)

| 구분 | 내용 |
|---|---|
| 연습실 페이지 | 자료 기반 문제 + AI 사용 횟수·글자수 제한을 재현한 웹 연습실. 문제 풀이, 첨부 파일 보기, 객관식·주관식 자동 채점, AI 질문(제한 있음)과 서술형 채점 |
| 실전형 과제 3문제 | 객관식·주관식·서술형으로 구성된 데이터 분석 과제(행사 집계, 라이선스 운영 분석, 수율 원인 분석) |
| AI 리터러시 문제집 | 3세트 30문항(RAG·프롬프트 / 보안·개인정보 / 규제·윤리·운영) |
| 실전 플레이북 | 시험 중 옆에 두고 보는 풀이 순서·시간 배분·검증 요령 |
| 프롬프트 템플릿 | 문항형 풀이·검증, 보고서형 계획용 |

## 2차 예선 (Cofa Probe 실무형 과제)

| 구분 | 내용 |
|---|---|
| 응시 환경 재현 | Cofa Probe 응시 화면(웹 IDE + AI CLI + 실무자 채팅)을 로컬 VS Code + Claude Code로 재현한 모의 시험 하네스. 시작·실무자 채팅·사후 Q&A·채점을 명령 하나씩으로 실행 |
| 연습 시나리오 3종 | 실무자에게 질문해 숨은 요구사항을 찾아내야 하는 실무형 웹 과제. 그중 1종은 실제 2차 예선과 같은 유형(로그인·DB·확정 흐름이 있는 웹 서비스) |
| 3축 채점기 | 기술(결과물)·의도(과정)·인지(이해도) 축으로 AI 대화·실무자 대화·커밋·실행 기록을 모아 채점 리포트 생성. 결과물 자동 검증 포함 |
| 사후 Q&A 연습 | 내 결과물과 로그로 질문을 만들고 AI 없이 답하는 연습 |
| 2차 예선 정리·팁 | 일정·준비물·화면 구성·평가 관점·상위권 패턴, 사전 체험 체크리스트 |
| 응시 요령(플레이북) | 실무자 인터뷰 순서, PRD·AGENTS.md 작성법, 검증 루프 등 |
| 후기·회고 | 본시험(10/31)과 재응시(11/4·5) 후기 정리, 개인 회고 |

문제·시나리오 속 회사·인물·수치는 모두 가상입니다.
